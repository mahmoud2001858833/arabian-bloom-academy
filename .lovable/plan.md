
# خطة إضافة نظام اللغات المتعددة للمنصة

## نظرة عامة
سيتم إضافة نظام ترجمة احترافي للمنصة يدعم 6 لغات مع واجهة اختيار لغة سهلة الاستخدام.

## اللغات المدعومة
| اللغة | الكود | الاتجاه | اسم الزر |
|-------|-------|---------|----------|
| العربية (الافتراضية) | ar | RTL | العربية |
| الإنجليزية | en | LTR | English |
| الماليزية | ms | LTR | Melayu |
| الأوردو | ur | RTL | اردو |
| الإندونيسية | id | LTR | Bahasa Indonesia |
| الفرنسية | fr | LTR | Francais |

---

## الميزات الرئيسية

1. **زر اختيار اللغة في شريط التنقل**
   - قائمة منسدلة أنيقة مع أيقونة الكرة الأرضية
   - كل لغة معروضة باسمها الأصلي
   - تخزين اختيار اللغة في localStorage

2. **ترجمة شاملة**
   - جميع صفحات الموقع
   - رسائل النظام والتنبيهات
   - نصوص الأزرار والقوائم
   - المرشد الذكي

3. **دعم اتجاه النص**
   - تبديل تلقائي بين RTL/LTR
   - تعديل التنسيقات حسب اللغة

## التفاصيل التقنية

### 1. هيكل ملفات الترجمة

```text
src/
├── i18n/
│   ├── index.ts          # إعداد i18n الرئيسي
│   ├── LanguageContext.tsx  # سياق اللغة
│   └── locales/
│       ├── ar.ts         # العربية
│       ├── en.ts         # English
│       ├── ms.ts         # Melayu
│       ├── ur.ts         # اردو
│       ├── id.ts         # Bahasa Indonesia
│       └── fr.ts         # Francais
```

### 2. محتوى ملفات الترجمة

كل ملف ترجمة سيحتوي على:

- **nav**: روابط التنقل (الرئيسية، الكورسات، من نحن)
- **auth**: نصوص تسجيل الدخول والاشتراك
- **home**: نصوص الصفحة الرئيسية
- **courses**: نصوص صفحة الكورسات
- **about**: نصوص صفحة من نحن
- **dashboard**: نصوص لوحة الطالب
- **common**: نصوص عامة (أزرار، رسائل)
- **guide**: نصوص المرشد الذكي
- **payment**: نصوص نظام الدفع

### 3. سياق اللغة (LanguageContext)

```tsx
interface LanguageContextType {
  language: string;
  setLanguage: (lang: string) => void;
  t: (key: string) => string;
  dir: 'rtl' | 'ltr';
}
```

### 4. مكون اختيار اللغة

سيظهر في شريط التنقل كقائمة منسدلة:
- أيقونة Globe مع السهم
- قائمة بجميع اللغات باسمها الأصلي
- علامة اختيار على اللغة الحالية
