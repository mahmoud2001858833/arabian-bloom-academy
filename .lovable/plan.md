# ترجمة الفيديوهات تلقائياً (صوت ← نص ← لغة الطالب)

عند رفع فيديو الدرس من لوحة التحكم، يتم تفريغ الصوت العربي إلى نص مع التوقيتات، ثم ترجمته إلى اللغات الست، وعرضه كـ Subtitles على المشغّل حسب اللغة التي اختارها الطالب في المنصة.

## تجربة الاستخدام

- **الأدمن:** بعد رفع الفيديو يظهر زر "توليد الترجمة التلقائية" بجانب الدرس، مع حالة (قيد المعالجة / جاهزة / فشلت) وإمكانية إعادة المحاولة. تشغيل تلقائي مباشرة بعد اكتمال الرفع.
- **الطالب:** الترجمة تظهر تلقائياً أسفل الفيديو بلغة واجهته الحالية، مع زر لإخفاء/إظهار الترجمة أو اختيار لغة أخرى.
- إذا لم تكن الترجمة جاهزة بعد، يعمل الفيديو بشكل طبيعي بدون ترجمة.

## الخطوات

1. **قاعدة البيانات:** جدول `lesson_subtitles` (lesson_id، اللغة، محتوى WebVTT، الحالة، تاريخ التوليد) مع RLS: قراءة للجميع، كتابة للأدمن/الخدمة فقط. وحقل حالة المعالجة على الدرس.
2. **دالة خلفية `transcribe-lesson-video`:** تستقبل `lesson_id`، تجلب رابط الفيديو من Cloudflare R2، وترسله إلى نموذج Gemini عبر Lovable AI Gateway لاستخراج نص عربي مقسّم بمقاطع زمنية.
3. **الترجمة:** نفس الدالة ترسل المقاطع الزمنية إلى النموذج لترجمتها إلى: الإنجليزية، الماليزية، الأردية، الإندونيسية، الفرنسية — مع الحفاظ على نفس التوقيتات.
4. **الحفظ:** توليد ملف WebVTT لكل لغة وتخزينه في `lesson_subtitles`.
5. **لوحة التحكم:** ربط زر التوليد وعرض الحالة داخل إدارة الدروس.
6. **المشغّل:** تحميل ملفات الترجمة وإضافتها كـ `<track>` داخل `VideoPlayer` مع تفعيل لغة الواجهة الحالية افتراضياً.

## تفاصيل تقنية

- نموذج التفريغ: `google/gemini-2.5-flash` عبر `https://ai.gateway.lovable.dev/v1/chat/completions` باستخدام كتلة `video_url` (رابط R2 عام) — لا حاجة لمفتاح Google Translate أو خدمة خارجية.
- الترجمة تتم بنفس نمط `translate-content` الحالي (JSON منظّم) للحفاظ على الاتساق.
- الفيديوهات الطويلة جداً تُعالج على دفعات زمنية لتفادي حدود حجم الطلب، مع معالجة أخطاء 429/5xx بإعادة محاولة محدودة.
- الملفات المتأثرة: ترحيل قاعدة بيانات جديد، `supabase/functions/transcribe-lesson-video/index.ts`، `src/components/dashboard/VideoPlayer.tsx`، `src/components/dashboard/DualVideoUploader.tsx`، `src/components/admin/SortableLessonsList.tsx` / `src/pages/Admin.tsx`.

## ملاحظة
