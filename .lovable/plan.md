

# خطة إضافة قسم المدونة

## نظرة عامة
سيتم إضافة قسم كامل للمدونة يشمل:
- صفحة عرض المدونات للزوار
- نظام إدارة المدونات في لوحة تحكم الأدمن
- ترجمة تلقائية للمحتوى إلى جميع اللغات المدعومة (6 لغات)

---

## المراحل الرئيسية

### المرحلة 1: إنشاء جدول المدونات في قاعدة البيانات

سيتم إنشاء جدول جديد `blog_posts` يحتوي على:
| العمود | النوع | الوصف |
|--------|------|-------|
| id | uuid | المعرف الفريد |
| title_ar | text | العنوان بالعربية |
| title_en | text | العنوان بالإنجليزية |
| title_ms | text | العنوان بالملايو |
| title_ur | text | العنوان بالأردو |
| title_id | text | العنوان بالإندونيسية |
| title_fr | text | العنوان بالفرنسية |
| description_ar | text | الوصف بالعربية |
| description_en | text | الوصف بالإنجليزية |
| ... | ... | باقي الوصف لكل لغة |
| content_ar | text | المحتوى الكامل بالعربية |
| content_en | text | المحتوى بالإنجليزية |
| ... | ... | باقي المحتوى لكل لغة |
| image_url | text | رابط صورة المدونة |
| is_published | boolean | حالة النشر |
| created_at | timestamp | تاريخ الإنشاء |
| updated_at | timestamp | تاريخ التحديث |

**سياسات الأمان (RLS):**
- الجميع يمكنهم قراءة المدونات المنشورة
- فقط الأدمن يمكنه إضافة/تعديل/حذف المدونات

---

### المرحلة 2: إنشاء Edge Function للترجمة التلقائية

سيتم إنشاء `translate-blog` Edge Function تستخدم Lovable AI لترجمة المحتوى تلقائياً إلى جميع اللغات المدعومة.

**آلية العمل:**
1. الأدمن يدخل العنوان والوصف والمحتوى (بأي لغة)
2. يضغط على زر "ترجمة تلقائية"
3. الـ Edge Function تستخدم Gemini AI لترجمة النص لكل اللغات
4. يتم ملء الحقول تلقائياً

---

### المرحلة 3: إضافة رابط المدونة في الهيدر

**تحديث Navbar.tsx:**
- إضافة رابط "المدونة" في قائمة التنقل (Desktop + Mobile)
- الرابط يوجه إلى `/blog`

**تحديث ملفات الترجمة:**
- إضافة `nav.blog` لكل اللغات الست

---

### المرحلة 4: إنشاء صفحة عرض المدونات

**إنشاء Blog.tsx:**
- عرض قائمة المدونات المنشورة بتصميم بطاقات جميل
- البحث والفلترة
- عرض المحتوى باللغة المختارة حالياً

**إنشاء BlogDetails.tsx:**
- عرض تفاصيل مدونة واحدة
- الصورة + العنوان + الوصف + المحتوى الكامل

---

### المرحلة 5: إضافة إدارة المدونات في لوحة الأدمن

**تحديث Admin.tsx:**
- إضافة تبويب جديد "إدارة المدونة"
- نموذج إضافة/تعديل مدونة يشمل:
  - حقل العنوان
  - حقل الوصف
  - حقل المحتوى (Textarea كبير)
  - رفع صورة المدونة
  - زر "ترجمة تلقائية" لترجمة المحتوى
  - حقول عرض الترجمات لكل لغة (قابلة للتعديل)
- قائمة المدونات مع خيارات التعديل والحذف والنشر

## التفاصيل التقنية

### 1. هيكل قاعدة البيانات

```text
┌─────────────────────────────────────────┐
│              blog_posts                 │
├─────────────────────────────────────────┤
│ id (uuid, PK)                           │
│ title_ar, title_en, title_ms, ...       │
│ description_ar, description_en, ...     │
│ content_ar, content_en, content_ms, ... │
│ image_url (text)                        │
│ is_published (boolean, default: false)  │
│ created_at (timestamp)                  │
│ updated_at (timestamp)                  │
└─────────────────────────────────────────┘
```

### 2. Edge Function للترجمة

- اسم الـ Function: `translate-blog`
- تستخدم `google/gemini-3-flash-preview` عبر Lovable AI Gateway
- تأخذ النص المصدر ولغته
- تُرجع ترجمة لجميع اللغات الست

### 3. الملفات الجديدة

| الملف | الوصف |
|-------|-------|
| `src/pages/Blog.tsx` | صفحة عرض المدونات |
| `src/pages/BlogDetails.tsx` | صفحة تفاصيل مدونة |
| `src/components/admin/BlogManagement.tsx` | إدارة المدونات في الأدمن |
| `supabase/functions/translate-blog/index.ts` | ترجمة تلقائية |

### 4. الملفات المعدلة

| الملف | التعديل |
|-------|---------|
| `src/components/layout/Navbar.tsx` | إضافة رابط المدونة |
| `src/App.tsx` | إضافة مسارات Blog |
| `src/pages/Admin.tsx` | إضافة تبويب المدونة |
| `src/i18n/locales/*.ts` | إضافة ترجمات المدونة (6 ملفات) |

### 5. سياسات RLS للأمان

```text
blog_posts:
  ├── SELECT: (is_published = true) → للجميع
  ├── ALL: has_role(auth.uid(), 'admin') → للأدمن فقط
```
