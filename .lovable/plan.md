
# خطة التغييرات المطلوبة

## ملخص التغييرات

سيتم تنفيذ مجموعة من التغييرات الشاملة على المنصة تشمل: إضافة زر واتساب عائم، تحديث المصطلحات، تبسيط الفوتر، وتحسين تجربة التسجيل في الدورات.

---

## 1. إضافة زر واتساب عائم

| التفصيل | القيمة |
|---------|--------|
| الرقم | +962 7 9943 1399 |
| الموقع | زاوية الشاشة (أسفل يسار) |
| التصميم | دائرة خضراء مع أيقونة واتساب |

سيتم إنشاء مكون جديد `WhatsAppButton.tsx` يظهر في جميع الصفحات.

---

## 2. تغيير المصطلحات

### تحويل "محتوى حصري" إلى "محتوى تفاعلي"
- تحديث في `HeroSection.tsx` 
- تحديث جميع ملفات الترجمة (ar, en, ms, ur, id, fr)

### تحويل "الكورسات" إلى "الدروس"
سيتم تحديث جميع الترجمات في الملفات التالية:
- `nav.courses` → "الدروس" / "Lessons"
- `home.browseCourses` → "تصفح الدروس"
- `courses.ourCourses` → "دروسنا"
- `dashboard.myCourses` → "دروسي"
- جميع المراجع الأخرى للكلمة

---

## 3. تبسيط الفوتر

### العناصر التي ستُحذف:
- قسم "مستويات التعلم" (المبتدئ، المتوسط، المتقدم)
- قسم "رسالتنا" 
- رمز "بسم الله الرحمن الرحيم" (﷽)

### الفوتر الجديد سيحتوي على:
- الشعار والوصف
- الروابط السريعة فقط
- حقوق النشر

---

## 4. إزالة فلتر المجاني/المدفوع من صفحة الدروس

سيتم حذف القائمة المنسدلة الخاصة بتصفية السعر (مجاني/مدفوع) من صفحة `Courses.tsx`.

---

## 5. تحسين تجربة التسجيل في الدورات

### السيناريو الجديد:

```text
المستخدم يضغط على "التسجيل في الدورة"
          │
          ▼
┌─────────────────────────────────┐
│   هل المستخدم مسجل دخول؟        │
└─────────────────────────────────┘
          │
    ┌─────┴─────┐
    │           │
   نعم         لا
    │           │
    ▼           ▼
عرض نافذة   توجيه لصفحة
الدفع       تسجيل الدخول
```

### قبل الاشتراك والدفع:
- يظهر: عنوان الدورة، الوصف، السعر، المستوى، عدد الدروس
- **يختفي**: قائمة الدروس والفيديوهات

### بعد الاشتراك والدفع:
- يظهر كل شيء (الدروس + الفيديوهات + التقدم)

```tsx
// WhatsAppButton.tsx
const WhatsAppButton = () => {
  const phoneNumber = "962799431399";
  const whatsappUrl = `https://wa.me/${phoneNumber}`;
  
  return (
    <a 
      href={whatsappUrl}
      target="_blank"
      className="fixed bottom-6 left-6 z-50 ..."

      <FaWhatsapp />
    </a>
  );
};
```
